## 2. 자동화 불가 항목과 사유

### 2-1. CMC 출력 제약 (가장 큰 원인)

현재 CMC 시트와 `cmengine.py`는 **전압/전류 크기 + 주파수만** 제어할 수 있고, 위상은 0°/240°/120° 평형으로 고정되어 있다. 따라서 다음이 불가능하다.

| 제약 | 막히는 TC | 내용 |
| --- | --- | --- |
| 전류 위상(역률) 제어 불가 | TC0022(일부), TC0023, TC0026, TC0030~0033, TC0036, TC0051 | PF 0.5/0.8, sinφ 조건, 4상한 무효전력, B상만 +30° 이동 등 |
| 고조파 주입 불가 | TC0041~0045, TC0048(일부), TC0052, TC0046/0047(조건2) | 3/5/7차 고조파 중첩 파형 생성 불가 |
| 위상 불평형 불가 | TC0054(위상 조건), TC0049, TC0050(위상 지정 조건) | Vb만 −10° 등 위상만 바꾸는 조건 |

**개선 제안**: CMC 시트에 위상 컬럼(Va_deg, Ia_deg …)과 고조파 컬럼을 추가하고 `cmengine._write_step_outputs()`의 `phases` 파라미터를 xlsx에서 받도록 확장하면 TC0023, 0026, 0027(위상 방식), 0032, 0051, 0054 위상 조건까지 자동화 범위가 크게 늘어난다. CMC256plus 자체는 위상·고조파 출력을 지원한다.

### 2-2. 전력량(에너지) 적산 시험 (TC0029~0036)

- TC 원문은 조건당 **1.0 h 적산**을 요구한다. 자동 시퀀스로 넣으면 케이스당 1시간 이상 소요.
- 시간을 줄이면(예: 60초) 적산량이 0.055 kWh 수준인데, 계측 레지스터(4189~4205)가 **UINT32, kWh 정수 단위**라 분해능이 부족해 판정 불가.
- Class 0.5S/1S 정밀도 판정은 기준 전력량계와의 대조가 필요해 본 하네스 범위를 벗어남.
- → 수동(또는 장시간 별도 시퀀스) 시험으로 분류. 송전(delivered) 적산은 전류 위상 반전이 필요하나, Current Direction=Reverse 설정으로 대체 가능하다는 점은 확인함(TC0027 참조).

### 2-3. 레지스터/기능 부재

| TC | 사유 |
| --- | --- |
| TC0049, 0050 (잔류전압/잔류전류) | Modbus Map(VER.2025)에서 A2700M 계측 영역(4001~4205)에 잔류전압/전류 레지스터를 찾지 못함. TC 원문에도 "화면 경로 확인 필요"로 표기됨. 판독 주소 확인 후 추가 필요 |
| TC0037 (Energy Unit Wh/kWh) | 설정 경로가 D화면 `SETUP > SYSTEM > Locale`뿐이고 대응 Modbus 레지스터 없음 → SETUP 화면 터치 시나리오는 setup_test 영역이라 수동 분류 |
| TC0034 (하위 9자리 표시) | Energy Set은 우회 기입 가능하지만 판정 대상이 **화면 표시 자릿수**라 POWER ENERGY 화면 OCR 좌표 필요. 좌표 확보 후 Expected 시트에 추가 가능 |
| TC0035 (재기동 후 복원) | 하네스에 DUT 전원 재기동 제어 수단 없음 |
| TC0053 (analysis 판독) | 고조파 화면 판독은 고조파 주입 불가와 동일 사유 |

### 2-4. 러너 판정 로직의 한계 (사용자 확인/개선 필요)

1. **Expected = 0 판정 불가**: 허용오차가 `|expected| × tol%`라 기대값이 0이면 허용폭도 0. TC0012-01(입력 4V→0V), TC0020-01(19mA→0A)은 기기가 정확히 0.0을 반환할 때만 PASS. 절대 허용오차(abs tolerance) 옵션 추가를 권장.
2. **INT64 미지원**: Energy Set 레지스터(51942~, INT64 4워드)를 uint32 2회(상위/하위) 분할 기입으로 우회했다(TC0038~0040). **실기에서 워드 순서(big-endian 가정)와 분할 기입 허용 여부를 반드시 검증**할 것. 실패 시 러너에 int64 value_type 추가 필요.
3. TC0038 최대 경계값(4,611,686,018,427,387,903 kWh)은 판독 레지스터(4189, UINT32)의 범위를 초과해 통신으로 검증 불가 → 수동.

### 2-5. 입력 정책(경계값 거부) 시험 (TC0011, 0021)

유효 경계값(1/20V, 1/100mA)의 쓰기·저장 확인은 자동화했다. 다만 **범위 밖 값(0V, 21V / 0mA, 101mA) 입력 시 거부 동작**은 Modbus로 쓰면 기기가 클램프하는지, 거부하는지, 그대로 저장하는지 정의가 없어 넣지 않았다. D화면 키패드 입력 정책(입력 필드 자체 제한)은 화면 시나리오라 수동 분류.
