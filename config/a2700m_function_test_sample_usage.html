A2700M 기능 테스트 샘플 사용 방법

파일: a2700m_function_test_sample.xlsx

목적

이 샘플은 CMC256plus로 A2700M에 전압/전류 조건을 인가한 뒤, A2700D 화면에 표시되는 계측값을 OCR로 읽어서 PASS/FAIL 판정하는 기능 테스트 양식입니다.

CMC 출력값 자체를 검증하는 파일이 아닙니다. CMC 출력은 DUT에 주는 자극이고, 판정 대상은 A2700D 화면의 표시값입니다.

실행 방법

  1. 앱을 실행하고 상단에서 A2700 장비 Modbus 연결을 먼저 완료합니다.
  2. Test 탭에서 Connect CMC로 CMC256plus를 연결합니다.
  3. Load Excel을 눌러 config/a2700m_function_test_sample.xlsx를 불러옵니다.
  4. TC 목록이 표시되면 START를 눌러 실행합니다.
  5. 실행 결과는 python_scripts/results/source_YYYYMMDD_HHMMSS 폴더에 CSV와 캡처 이미지로 저장됩니다.

시트 구성

시트 역할 작성 포인트
TestCases 실행할 TC 단위 정의 Enable이 TRUE인 행만 실행됩니다.
SetupModbus 테스트 전 필요한 설정값을 통신으로 빠르게 write Address와 Access Address는 Modbus Map 문서 주소 기준입니다. 코드는 내부에서 -1을 적용합니다.
CMC CMC256plus 출력 조건 전압, 전류, 주파수, 유지 시간을 정의합니다.
Navigation A2700D 화면 이동 좌표 setup_test_a2700.xlsx와 같은 x,y; x,y 형식입니다.
Expected OCR 판정 기준 ROI 안에서 숫자, 단위, Required Text를 확인합니다.
Guide 작성 규칙 요약 파일 안에서도 규칙을 빠르게 확인할 수 있습니다.

SetupModbus 작성 규칙

  • Address: Accura 2700m Modbus Map.xlsx에 적힌 문서 주소를 그대로 입력합니다.
  • Access Address: 해당 설정 그룹의 access 주소를 입력합니다.
  • Value Type: uint16, int16, uint32, int32, float 중 하나입니다.
  • Write Value: 테스트 전에 장비에 쓸 설정값입니다.
  • Access Value: 보통 1입니다.
이 테스트의 목적은 설정 UI 자체 검증이 아니므로, 설정값이 화면에서 잘 바뀌었는지는 여기서 판정하지 않습니다. 필요한 사전 설정만 Modbus로 빠르게 적용합니다.

Expected 작성 규칙

  • Source Name은 CMC 시트의 Name과 맞춰야 합니다.
  • Expected는 화면에 표시되어야 하는 기대 숫자입니다.
  • Unit은 V, A, Hz처럼 OCR에서 확인할 단위입니다.
  • Tolerance Type은 percent 또는 absolute입니다.
  • roi_xy는 x1,y1,x2,y2 형식입니다. 실제 화면 캡처 기준으로 조정해야 합니다.
  • Required Text는 ROI 안에서 함께 확인할 라벨입니다. 예: Va, Ia
